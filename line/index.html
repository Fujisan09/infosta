公式LINEの素案

情報ステーションの公式LINEを開設したときの、見た目と文章の素案です。アカウントはまだ開設していません。開設したら、このページの文章と画像をそのまま設定に使えます。

ホームページで興味を持った人が友だち追加し、図書館さがし・本の寄贈・ボランティア・場所の相談へ進めるようにします。仲間を募る入口として「仲間になる」をメニューの左上に置きました。

スマホの画面はイメージです。実際の LINE の表示とは、細かいところが異なります。

リッチメニュー

トーク画面の下に出るメニューです。大きいサイズ（2500×1686px）の6分割にしました。LINE Official Account Manager でテンプレート「大・6分割」を選び、下の画像をアップロードして、各ボタンに「押したとき」の動きを設定します。

位置表示押したとき
左上仲間になるボランティア「仲間になりたい」と送られ、下の応答メッセージが返る
中央上図書館さがし公式サイトへ公式サイトの「民間図書館」を開く（新しいタブで開きます）
右上本を寄贈する寄贈の方法公式サイトの「本の寄贈」を開く（新しいタブで開きます）
左下活動を知る情報ステーションとは公式サイトの「情報ステーションとは」を開く（新しいタブで開きます）新しいホームページを公開したら、そのURLに変えます
中央下相談する場所・企画・なんでも「相談したい」と送られ、下の応答メッセージが返る
右下応援する会員・寄付公式サイトの「寄付・会員募集」を開く（新しいタブで開きます）

配信のひな形

活動の様子や参加の機会を、友だち全員に届けるときのひな形です。（ ）の中を書き換えて使います。下は見本で、実際の予定ではありません。

  • 活動の風景

    【今月の棚】
    （図書館の名前）の棚を入れ替えました。今月は（テーマ）の本が並んでいます。
    （写真）

    近くの図書館は、メニューの「図書館さがし」から。

  • 参加の機会

    【仲間を募集しています】
    （図書館の名前）で、（日にち）に棚づくりを手伝ってくださる方を募集しています。
    本が好きな方、はじめての方も歓迎です。
    催しの日でなくても、図書館はいつでも立ち寄れます。

    くわしくは、メニューの「仲間になる」から。

開設の手順

開設は、団体の担当者が行います（団体のメールアドレスで作ると、担当が替わっても引き継げます）。

  1. LINEビジネスIDを作る

    開設ページの「LINE公式アカウントをはじめる」から「メールアドレスで登録」を選び、団体のメールアドレス（例：office@infosta.org）で登録します。途中で、電話番号（SMS）での確認があります。

    LINE公式アカウントの開設ページ（新しいタブで開きます）

  2. アカウントを開設する

    アカウント名（情報ステーション）などを入れて開設します。途中で、団体として持つための「組織」（ビジネスマネージャー）も作ります。最初は審査のない「未認証アカウント」です。

  3. プロフィールを整える

    プロフィール画像（ロゴ）・背景の写真・ステータスメッセージ・基本情報を、このページのとおりに入れます。

  4. メッセージを入れる

    あいさつメッセージ・応答メッセージを、このページからコピーして貼り付けます。

  5. リッチメニューを設定する

    テンプレート「大・6分割」を選び、画像をアップロードして、6つのボタンの動きを設定します。

  6. ホームページとつなぐ

    友だち追加のURLをコピーして、ホームページの設定（content/site.json の links.lineUrl）に入れます。相談窓口に「LINEで友だち追加」のボタンが出ます。

費用と、決めておくこと

料金

無料のプラン（コミュニケーションプラン）で始められます。友だち全員への配信は、月200通までです。通数は「配信の回数 × 受け取る友だちの数」で数えます（あいさつメッセージ・応答メッセージ・個別のトークは数えません）。

  • 友だち50人全員への配信は、月4回まで
  • 友だち100人全員への配信は、月2回まで
  • 200人を超えると無料のプランでは、全員に月1回も届けられなくなります。その時点で、月5,000円・5,000通のライトプラン（税別）を検討します

料金・手順は、LINEヤフーの案内（料金：2025年9月2日更新、開設の手順：2026年10月9日更新）で確かめた内容です。変わることがあるため、開設のときに確認してください。

LINE公式アカウントの料金プラン（LINEヤフー for Business）（新しいタブで開きます）

審査に通ると「認証済アカウント」になり、緑のバッジがつき、LINEアプリの中の検索にも出るようになります（開設したあとに申請）。

開設の前に決めておくこと

  • アカウントの持ち主（団体のLINEビジネスID）と、管理画面に入れる人
  • 配信の担当と、無理のない頻度（毎週などの約束はしない）
  • LINEのトークで個別にお返事をするか（チャット）と、その担当
  • 配信に使う写真の掲載の同意（写っている人・図書館）
  • 「活動を知る」の行き先（新しいホームページを公開したら差し替え）
